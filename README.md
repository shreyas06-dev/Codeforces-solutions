\# Codeforces, in Public



Every Codeforces problem I solve, posted in public — solutions, notes, and the occasional L — organized by rating as I grind toward Expert.



\## 📊 Stats

\- Solved: 1

\- Current rating: unrated

\- Goal: 1600 Expert



\## 📁 Structure

Solutions are organized by rating bucket:

\- `800-899/` — rating 800–899

\- `900-999/` — rating 900–999

\- ...and so on



Files are named `<ProblemID>-<Name>.<ext>` so they're easy to search.



\## 📝 Notes

Approach notes live in the file header for problems that taught me something worth remembering.



\## 🎯 Why public?

Accountability — knowing someone might read the notes makes me write better notes. And the CF community shares approaches; this is my small contribution back while I'm early in my journey, I just want to grow authentically without thinking im too late or having the regret that I should've started sooner, so here I am





If you're on the same path, steal the structure, the templates, whatever helps.
